# Phrase Analyzer

Angular app for analyzing text: character and word count, synonyms for a selected word or phrase (via the [Datamuse API](https://www.datamuse.com/api/)), and replacing the selection in the textarea.

> Work in progress — full description, decisions and live demo will be added when the feature is complete.

## Getting started

Requires Node.js 22.12+.

```bash
npm ci
npm start          # http://localhost:4200
npm test           # unit tests (Vitest)
npm run check      # Biome lint + format
npm run typecheck
npm run build
```
